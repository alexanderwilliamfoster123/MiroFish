# Tradr — Trade. Compete. Win.

A Revolut-style, dark-premium, **fully-3D and interactive** marketing site for a
**trading-competition** company. The whole site is a single, double-clickable HTML
file: Three.js is inlined and the reflection environment is generated in code, so
it runs offline straight from a `file://` URL — no server, no internet.

## Just open it

Double-click **`tradr.html`**. That's it.

## What's in it

A single-page app with hash routing and a distinct 3D hero per page:

| Route | Page | 3D object |
|---|---|---|
| `#home` | Trade. Compete. Win. | Gold "T" medal |
| `#competitions` | Browse contests | Stack of coins + spinning coin |
| `#leaderboard` | Live rankings | Gold/silver/bronze podium |
| `#how` | How it works | Orbiting medals + rings |
| `#prizes` | Prize tiers | Gold trophy cup |
| `#about` | Company | Gold "T" medal |
| `#signup` | Join (form w/ success state) | — |
| `#login` | Log in (routes to leaderboard) | — |

## Interactive, not just animated

- **Drag the 3D** — click/touch and drag anywhere to spin the object, with inertia.
- **Live leaderboard** — ranks, equity and P&L update every ~1.2s and re-sort in
  real time (home preview + full leaderboard page).
- **Scroll-driven** — objects drift and the camera moves as you scroll.
- Sticky glass nav, mobile menu, scroll-reveal sections, working forms.

## Branding

Consistent **Tradr** identity throughout: the gradient "T" mark in the nav, footer,
loader and forms; a green→violet brand gradient (`--grad`) with gold for prizes;
the same voice ("the arena", "Trade. Compete. Win.") on every page.

## Rebuild

`tradr.html` is generated by `build-tradr.js` (inlines Three.js + assembles the
views/app). To regenerate after edits:

```bash
# needs three@0.160.0 installed locally for the UMD build
node build-tradr.js
```

Demonstration only — not a real trading product.
