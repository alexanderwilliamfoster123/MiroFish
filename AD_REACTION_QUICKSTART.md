# Ad Reaction Studio — Quickstart

Drop a headline in, pick pages from the seeding roster, and watch LLM persona
agents simulate each page's audience reacting — before anything is posted for real.

The studio lives at **http://localhost:3000/ad-reaction** once the app is running.

## 1. Get the code (this feature's branch)

```bash
git clone https://github.com/alexanderwilliamfoster123/MiroFish.git
cd MiroFish
git checkout claude/ad-reaction-dashboard-fhmu4u
```

## 2. Configure the LLM

Copy the env template and add any **OpenAI-compatible** API key
(OpenAI, DashScope/Qwen, DeepSeek, etc.):

```bash
cp .env.example .env
```

```env
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://api.openai.com/v1        # or your provider's URL
LLM_MODEL_NAME=gpt-4o-mini                    # or your provider's model
```

> The Ad Reaction Studio only needs the LLM settings. `ZEP_API_KEY` is required
> for the full MiroFish world-simulation pipeline, not for the studio.

## 3. Install & run

Prerequisites: Node.js 18+, Python 3.11–3.12, [uv](https://docs.astral.sh/uv/).

```bash
npm run setup:all     # first time only — installs root, frontend and backend deps
npm run dev           # starts backend (5001) + frontend (3000)
```

Open **http://localhost:3000/ad-reaction**:

1. Type your headline (and optional caption).
2. Filter/search the roster and select up to 10 pages.
3. Hit **Run simulation** — each page's audience is simulated concurrently
   (about 10–30 seconds depending on your LLM provider).

## Demo mode (no API key needed)

To try the studio without any LLM key, run the bundled demo shim, which serves
pre-authored reactions for six sample pages (Theaifield, Futuretechnews.ai,
Entrepreneurinsights, Datasciencebrain, Hoodclips, Dailywtfacts):

```bash
# terminal 1 — fake LLM on port 5099
python backend/scripts/ad_reaction_demo_llm.py
```

Point `.env` at the shim:

```env
LLM_API_KEY=demo-key
LLM_BASE_URL=http://127.0.0.1:5099/v1
LLM_MODEL_NAME=mirofish-demo
```

Then `npm run dev` as usual and simulate against those six pages. Other pages
return a labelled placeholder in demo mode.

## What the results mean

Reactions are generated by LLM persona agents inferring each audience from its
page handle — a fast, honest first read, **not real user data**. Accuracy
improves as pages gain ingested comment histories and full MiroFish world
simulations (the standard project flow in the app).

## API

- `GET /api/ad-reaction/roster` — the seeded-page roster (152 unique pages,
  deduplicated, keyword-grouped)
- `POST /api/ad-reaction/simulate` — body:
  `{"headline": "...", "caption": "...", "pages": ["Theaifield", ...]}`
  (max 10 pages per run)
